# Roadmap

The toolkit grows through complete creator workflows rather than untested provider names.

## Current

- Persistent queue, one-model GPU lifecycle, hardware diagnostics, and benchmark records
- Local speech, image generation, inpainting, vision, segmentation, and upscaling
- LTX text-to-video and image-to-video with low-VRAM fallback
- Narration, social clip, thumbnail, and AI Short workflows

## Next

1. Validate every model on the target RTX 4060 Ti and record real benchmarks.
2. Add ACE-Step music and local sound effects.
3. Add optional frame interpolation and clip approval metadata.
4. Build podcast and faceless long-form workflows.
5. Add disk checks, resumable steps, cleanup tools, and previews.
6. Add a small local web interface after the API workflows stabilize.

See [implementation-checklist.md](implementation-checklist.md) for detailed progress.
