# Roadmap

The toolkit grows through complete creator workflows rather than disconnected provider demos.

## Current

- persistent local queue and one-model GPU lifecycle
- durable project runs and artifact-aware model checkpoints
- project resume controls
- readiness and storage diagnostics
- dry-run-first cleanup with active-project protection
- reusable music and sound-effect presets
- GPU diagnostics and benchmark records
- local speech, image, video, music, and sound-effect backends
- narration, thumbnail, social clip, AI Short, and podcast workflows
- background music and timed sound-effect mixing
- duration, volume, and clipping-risk validation
- standard-library reliability tests

## Next

1. Validate every model on the target RTX 4060 Ti and tune defaults from recorded benchmarks.
2. Add 8GB, 16GB, and 24GB hardware profiles.
3. Add generated-output previews and project artifact browsing.
4. Build faceless documentary and storytelling workflows.
5. Add automatic long-video highlight selection.
6. Add a small local web interface after the API remains stable.

See [implementation-checklist.md](implementation-checklist.md) for detailed progress.
