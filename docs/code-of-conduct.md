# Code of Conduct

Be respectful, constructive, and considerate in repository issues, pull requests, reviews, and discussions.

Helpful participation includes clear technical feedback, reproducible examples, respect for different experience levels, and care when discussing media that may contain personal information.

Harassment, discrimination, threats, publishing private information, deliberate disruption, and repeated hostile behavior are not accepted.

Report conduct concerns privately through the maintainer's GitHub profile. Maintainers may edit or remove content, close discussions, restrict participation, or block contributors when necessary to protect the project community.
