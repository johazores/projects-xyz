# Changelog

Notable changes to the local media toolkit are documented here.

## Unreleased

### Added

- Open-source security, conduct, metadata, and repository documentation.

## 2026-07-30

### Added

- Practical audio transcription, enhancement, conversion, trimming, and normalization workflows.
- Image prompt presets, batch generation, and local background removal.
- Video resizing and frame extraction.
- A unified local FastAPI entry point for audio, image, and video workflows.
- Project-based output folders and capability reporting.

### Changed

- Repositioned the repository around useful local media processing rather than untested provider count.
- Kept optional models and provider dependencies isolated by project.
